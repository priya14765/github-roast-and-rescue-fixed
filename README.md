# github-roast-and-rescue

**GitHub Roast and Rescue** is a rule-based tool that evaluates a public GitHub profile and provides a **100-point score, honest roast, and personalized Rescue Plan**.

It analyses profile details, repositories, README quality, documentation, activity, commits, languages, and project health. Each finding is backed by actual GitHub data—**nothing is guessed**.

### Key Features
- 📊 Fixed **100-point GitHub score**
- 🔍 Repository health analysis
- 🔗 Evidence-backed findings
- 🔥 Honest profile roast
- 🚑 7-day Rescue Plan
- 📝 Improved README & repository descriptions
- 🎯 Priority fixes and project recommendations
- 🤖 Optional Gemini-powered wording polish
- 📄 Copy, print, and PDF-friendly reports
- 💾 Local progress tracking
- 🔐 Secure API-key handling
- ♿ Accessibility-focused UI

### Tech Stack
**Python • Flask • GitHub REST API • HTML/CSS/JavaScript • Gemini API • Docker**

**Goal:** Turn a messy GitHub profile into a **recruiter-ready portfolio** with clear, actionable improvements.
